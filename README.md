# 🌟 Fuad Bookmark Manager

A modern, highly responsive, and lightweight **Progressive Web App (PWA)** for managing bookmarks. Built entirely with Vanilla JavaScript, HTML5, and CSS3, featuring a sleek Glassmorphism UI and intelligent Netscape HTML Parsing.

🔗 **[Live Demo: Try it here!](https://fuadfadam.github.io/fuad-bookmark-manager/)**

---

## ✨ Key Features

- **🎨 Glassmorphism UI & Dark Mode:** A premium, modern interface with a built-in light/dark theme toggle that respects user preferences.
- **📱 Progressive Web App (PWA):** Fully installable on iOS, Android, and Desktop. Features offline caching via Service Workers.
- **🧠 Smart HTML Import/Export:** Parses standard Netscape Bookmark `.html` files perfectly. Import your existing bookmarks from Chrome/Firefox, and it automatically categorizes them!
- **🗂️ Advanced Category Management:** Create, rename, delete, and sort categories with full **Drag & Drop** support.
- **⚡ Zero Dependencies:** No React, No Vue, No NPM modules. Pure, highly optimized, and clean Vanilla JS.
- **💾 Local Storage Persistence:** All data is safely stored in the browser's IndexedDB/LocalStorage. Complete privacy, no backend required.
- **🔍 Real-time Search:** Instantly filter across hundreds of bookmarks by title or URL.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
- **Logic:** Vanilla JavaScript (ES6+, DOM Manipulation, Regex)
- **Storage:** Browser `localStorage`
- **PWA:** `manifest.json` & Service Workers (`sw.js`)

---

## 🚀 How to Use

1. **Visit the Live Site:** Go to the [Live Demo](https://fuadfadam.github.io/fuad-bookmark-manager/).
2. **Import Bookmarks:** Click the 📥 (Import) icon in the header to upload an `.html` bookmark backup from your browser.
3. **Install as App:** On mobile (Chrome/Safari), click "Add to Home Screen". On Desktop Chrome, click the install icon in the address bar.
4. **Manage:** Drag and drop folders to reorder them, edit URLs, or export your library as a standard HTML file anytime.
